# support-ticket-center

Самостоятельный интерактивный проект: обращения клиентов.

[Открыть сайт](https://cherreshenka1.github.io/support-ticket-center/) · [Кейс](https://cherreshenka1.github.io/portfolio/projects/support-ticket-center/) · [Промпт и критерии доработки](https://github.com/cherreshenka1/portfolio/blob/main/prompts/support-ticket-center.md)

## Сценарий

Найти обращение, написать ответ в демо-переписку и закрыть тикет.

Поиск и фильтры управляют очередью. У каждого обращения свой черновик ответа; пустая выборка скрывает переписку и блокирует действия.

## Границы

Переписка демонстрационная, сообщения клиентам не отправляются.

## Проверить вручную

1. Найти обращение.
2. Прочитать историю.
3. Добавить ответ.
4. Изменить статус.

Проверены основной сценарий и адаптивная вёрстка при ширине 390 и 1280 px. Это проверка прототипа, а не сертификация готовности к промышленной эксплуатации.

## Визуальная доработка

Перестроено 03.10.2026: самостоятельная композиция, навигация и пользовательский сценарий. Стили собраны в `src/project.css`; прежние общие оболочки отключены. Источники открытых данных: `public/data/open-data.json`; происхождение фотографий: `public/data/photo-sources.json`. Фотографии сохранены локально.

## Разработка

React 18, Vite 5. Node.js 20+.

```sh
npm ci
npm run dev
npm run build
```

`npm run deploy` собирает приложение и публикует `dist` в ветку `gh-pages` текущего репозитория.
