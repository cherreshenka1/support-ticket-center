# Support Ticket Center

SaaS-интерфейс центра поддержки: список тикетов, поиск, фильтры,
чат внутри обращения, SLA-индикаторы и сохранение состояния.

## Живая версия

[https://cherreshenka1.github.io/support-ticket-center/](https://cherreshenka1.github.io/support-ticket-center/)

## Возможности

- список обращений
- поиск по тикетам
- фильтрация по статусу и приоритету
- карточка обращения
- переписка внутри тикета
- SLA-индикатор срочности
- смена статуса
- добавление ответа оператором
- сохранение в `localStorage`

## Запуск

```bash
npm install
npm run dev
```

## Деплой

```bash
npm run deploy
```
